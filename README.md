# MediConnect — Página Responsiva com Bootstrap 5

Atividade prática da disciplina **Desenvolvimento Responsivo**  
Unidade 2 · Aula 4 — Layouts com Frameworks e Bibliotecas Front-End

## Estrutura do projeto

```
mediconnect/
├── index.html       ← página principal
├── css/
│   └── style.css    ← estilos personalizados
└── .gitignore
```

## Como abrir

1. Clone ou extraia a pasta
2. Abra no **VS Code**: `code .`
3. Abra `index.html` no navegador (ou use a extensão **Live Server**)

## Breakpoints utilizados

| Classe      | Dispositivo | Comportamento         |
|-------------|-------------|-----------------------|
| `col-12`    | Mobile      | 1 coluna (empilhadas) |
| `col-md-6`  | Tablet      | 2 colunas por linha   |
| `col-lg-4`  | Desktop     | 3 colunas lado a lado |

## Testar responsividade

Abra o navegador → **F12** → ícone de dispositivo móvel → redimensione a janela.
